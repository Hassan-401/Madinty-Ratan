# متجر Madinty Ratan

متجر إلكتروني بسيط لبيع الأثاث الخارجي — HTML + CSS + JavaScript فقط، بدون سيرفر أو قاعدة بيانات.
الطلب بيتبعت على الواتساب مباشرة.

## تشغيل الموقع

افتح `index.html` من المتصفح مباشرة، أو شغّل سيرفر محلي:

```bash
npx http-server . -p 5599 -c-1
```

## هيكل الملفات

```
index.html            الصفحة الرئيسية (هيرو بصورة خلفية + الأقسام + الأكثر طلبًا + نبذة)
products.html         جميع المنتجات + فلتر بالأقسام (products.html?cat=iron)
product.html          صفحة المنتج (product.html?id=p-101)
about.html            صفحة "من نحن" المنفصلة
contact.html          صفحة "تواصل معنا" المنفصلة (خريطة + طرق التواصل + نموذج)
cart.html             العربة + بيانات العميل + إرسال الطلب على الواتساب
assets/css/style.css  كل التنسيقات
assets/js/data.js     ⬅️ المنتجات والأقسام وبيانات المتجر (عدّل هنا)
assets/js/app.js      منطق العربة + الهيدر والفوتر + الأيقونات + رسالة الواتساب
assets/img/hero.jpg   خلفية الهيرو وبانر الصفحات الداخلية
assets/img/home.jpg   صورة قسم النبذة في الرئيسية
assets/img/p1..p5.jpg صور المنتجات
```

## الهيدر والهيرو

- الهيدر **ثابت (fixed)** في أعلى الصفحة: شفاف فوق صورة الهيرو في الصفحة الرئيسية،
  وبيتحول للون الداكن أوتوماتيك أول ما تنزل بالسكرول. في باقي الصفحات بيبقى داكن من البداية.
- الترتيب: اللوجو يمين · روابط القائمة في النص · أيقونتَي الحساب والعربة شمال.
- على الموبايل الروابط بتتحول لقائمة منسدلة بزرار ☰.
- لتغيير صورة الهيرو: استبدل `assets/img/hero.jpg` (يُفضّل عرض 1920 بكسل).
- روابط القائمة موجودة في `NAV_LINKS` داخل `assets/js/app.js`.
- الأيقونات (SVG) في كائن `ICONS` داخل نفس الملف.

## التعديلات الشائعة

كلها في `assets/js/data.js`:

| تعديل | مكانه |
|---|---|
| رقم الواتساب المستقبِل للطلبات | `STORE.whatsapp` (بصيغة دولية بدون +) مع `STORE.whatsappDisplay` |
| إضافة/تعديل منتج | مصفوفة `PRODUCTS` |
| إضافة/تعديل قسم | مصفوفة `CATEGORIES` |
| نص التوصيل وبيانات المصنع | `STORE` |

### إضافة منتج جديد

```js
{
  id: "p-117",                   // معرّف فريد
  cat: "iron",                   // id القسم من CATEGORIES
  img: "assets/img/p1.jpg",      // مسار الصورة
  featured: true,                // (اختياري) يظهر في "الأكثر طلبًا"
  name: "اسم المنتج",
  short: "وصف قصير يظهر تحت الاسم",
  price: 12000,                  // السعر الحالي
  oldPrice: 15000,               // (اختياري) السعر قبل الخصم — بيحسب نسبة الخصم تلقائيًا
  warranty: "10 سنوات",
  specs: ["مواصفة 1", "مواصفة 2"]
}
```

## طريقة عمل الطلب

1. العميل يضيف المنتجات للعربة (محفوظة في `localStorage` باسم `mr_cart_v1`).
2. في صفحة `cart.html` يملأ بياناته (الاسم، الموبايل، المحافظة، العنوان، ملاحظات).
3. عند الضغط على **تأكيد الطلب** يتم التحقق من البيانات، ثم يفتح الواتساب على الرقم
   الموجود في `STORE.whatsapp` برسالة جاهزة فيها تفاصيل الطلب — العميل يضغط "إرسال".
4. العربة تتفضى وتظهر رسالة تأكيد مع زر لإعادة الإرسال لو النافذة اتقفلت.

> **مهم:** واتساب لا يسمح بإرسال الرسالة تلقائيًا بدون تدخل المستخدم — العميل لازم
> يضغط زر الإرسال داخل الواتساب. ده سلوك طبيعي لكل المتاجر اللي بتستخدم wa.me.
>
> لو حبيت الطلب يوصلك تلقائيًا بدون تدخل العميل، هتحتاج سيرفر صغير + WhatsApp Cloud API.
