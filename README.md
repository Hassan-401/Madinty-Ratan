# Madinty Ratan — متجر الأثاث الخارجي

موقع متجر إلكتروني (HTML + CSS + JavaScript عادي) — من غير خطوة بناء ولا مكتبات.
الطلبات بتوصل صاحب المتجر على **الواتساب** وبتتسجّل في **لوحة التحكم**، والكتالوج
كله متخزن في **Cloudflare D1** فأي تعديل من اللوحة بيظهر للزوّار على طول.

> التشغيل والصيانة والدومين وحسابات الدخول كلها في **[SETUP.md](SETUP.md)**.

---

## التشغيل

```bash
npx wrangler dev      # نسخة محلية كاملة على http://localhost:8787
npx wrangler deploy   # نشر
```

`file://` مش هيشتغل — الروابط مطلقة والـAPI محتاج سيرفر.

## فين بتتخزن كل حاجة

| البيانات | مكانها | بتتعدّل منين |
| --- | --- | --- |
| المنتجات والأقسام | جدول `products` / `categories` في D1 | **لوحة التحكم** — بيظهر للزوّار على طول |
| الطلبات | جدول `orders` في D1 | بتتسجّل لوحدها، وبتتابعها من اللوحة |
| صور المنتجات الجديدة | R2 (bucket اسمه `madinty-ratan-media`) | زرار الرفع في نموذج المنتج |
| مصاريف الشحن والألوان والأرقام | `assets/js/data.js` | تعديل الملف + commit & push |

الصور القديمة لسه في `assets/img/` وبتتعرض عادي — قاعدة البيانات بتخزّن مسار
الصورة مش الصورة نفسها.

### التعديلات اللي لسه في `assets/js/data.js`

| عايز تغيّر | غيّر |
| --- | --- |
| رقم استقبال الطلبات | `STORE.whatsapp` (بصيغة دولية بدون +) و `STORE.whatsappDisplay` |
| الإيميل / مكان المصنع / المواعيد | `STORE.email` / `STORE.factory` / `STORE.hours` |
| مكان المصنع على الخريطة | `STORE.map.query` — أي عنوان أو إحداثيات `"30.55,30.98"` |
| مصاريف الشحن | `SHIPPING` — `0` = مجانًا، `null` = تُحدد عند التأكيد |
| ألوان الشلت | `CUSHION_COLORS` |

`DEFAULT_CATEGORIES` و `DEFAULT_PRODUCTS` بقوا **نسخة احتياطية** بس: الموقع
بيستخدمهم لو القاعدة مش متاحة، وزرار «استيراد الكتالوج الافتراضي» بينقلهم
للقاعدة. التعديل اليومي بيبقى من اللوحة.

### شكل المنتج (لو حبيت تعدّل النسخة الاحتياطية يدويًا)

```js
{
  id: "MR-IRON-09",                 // كود لا يتكرر
  cat: "iron-sets",                 // لازم يساوي id قسم موجود
  featured: true,                   // اختياري — يظهر في "الأكثر طلبًا"
  name: "طقم حديد علب 6 مقاعد",
  short: "كنبة 3 مقعد + 2 كرسي + ترابيزة",
  img: "assets/img/products/اطقم حديد علب/meatel 9.webp",
  price: 19500, oldPrice: 23000,    // oldPrice اختياري (يظهر كسعر قبل الخصم)
  components: ["كنبة 3 مقعد", "2 كرسي", "ترابيزة"],
  specs: ["حديد علب معالج", "دهان فرن إلكتروستاتك"],
  cushions: true,                   // اختيار لون الشلت إجباري على العميل
  warranty: "ضمان سنتين"            // اختياري
}
```

منتج ليه أكتر من نوع (زي الشمسية والهاموك):

```js
variants: [
  { name: "شمسية 3 متر", price: 4000, oldPrice: 5000 },
  { name: "شمسية 4 متر", price: 5000 }
]
```

لو النوع ليه سعر، السعر ده هو اللي بيتحسب في العربة.

## لوحة التحكم — `/admin`

الدخول بالإيميل وكلمة السر (شوف [SETUP.md](SETUP.md) لإضافة حساب أو تصفير كلمة سر).

| التبويب | بيعمل إيه |
| --- | --- |
| نظرة عامة | إجمالي المبيعات وعدد الطلبات والقطع المباعة + آخر الطلبات + الأكثر مبيعًا + مخزون منخفض |
| الطلبات | متابعة الطلبات، تغيير الحالة، التفاصيل، الحذف، تصدير CSV، وإضافة طلب من رسالة واتساب |
| المنتجات | إضافة / تعديل / حذف منتج بكل تفاصيله + رفع صورة + المخزون والرواج |
| الأقسام | إضافة / تعديل / حذف قسم |
| الإعدادات | استيراد الكتالوج الافتراضي، نسخة احتياطية، تغيير كلمة السر، مسح الطلبات |

> تغيير كلمة السر بيخرّج أي جهاز تاني داخل بنفس الحساب.

### المخزون

خانة **المخزون** اختيارية — سِبها فاضية لو مش بتتابع الكميات، وهتظهر «—» في الجدول.
لو حطيت رقم، المنتج بيظهر في لوحة **«مخزون منخفض»** لما يبقى **5 قطع أو أقل**.

### الصلاحيات

الكتابة مش مربوطة بمجرد إنك مسجّل دخول — لازم إيميلك يكون في جدول `admins`،
وده اللي الـWorker بيتأكد منه قبل أي كتابة.

المتصفح مالوش أي وصول مباشر لقاعدة البيانات، ومفيش أي مفتاح سري في الكود
المنشور — كل الأسرار في إعدادات الـWorker على Cloudflare.

كلمة السر بتتشفّر في المتصفح الأول (PBKDF2 بـ300 ألف دورة) وبعدين السيرفر
بيشفّر الناتج تاني بملح عشوائي. يعني كلمة السر نفسها عمرها ما بتخرج من الجهاز،
وحتى لو حد وصل للقاعدة مش هيعرفها.

### ⚠️ حاجتين لازم تعرفهم

**1) الطلب بيتسجّل قبل ما العميل يبعت الواتساب.**
أول ما يضغط «تأكيد الطلب» بيتحفظ في القاعدة وبعدين بتتفتح نافذة الواتساب.
يعني ممكن يوصلك طلب في اللوحة والعميل ما بعتش الرسالة — كلّمه على رقمه اللي في الطلب.

**2) أي حد يقدر يضيف طلب** (لازم كده عشان الزائر يطلب من غير تسجيل دخول).
فيه حد أقصى 15 طلب في الدقيقة لكل جهاز. لو ظهرت طلبات وهمية، امسحها عادي —
ولو المشكلة بقت كتير، الحل إضافة تحقّق زي Turnstile.

## رحلة الطلب

1. العميل يفتح صفحة المنتج ويختار **لون الشلت (إجباري)** ونوع الطقم لو المنتج ليه أنواع.
2. في `cart.html` يملأ بياناته ويختار المحافظة — **الشحن بيتحسب على طول** من جدول `SHIPPING`.
3. يضغط «تأكيد الطلب» ← الطلب **بيتسجّل في قاعدة البيانات** وبتتفتح نافذة واتساب برسالة جاهزة.
4. الرسالة بتحتوي على اسم المنتج والنوع و**لون الشلت** والكمية والأسعار والشحن وبيانات العميل.
5. **العميل بيضغط زر الإرسال بنفسه** — ده شرط من واتساب. حتى لو ما بعتش، الطلب موجود عندك في اللوحة.

## ملاحظات

- كل الصور بصيغة `webp`. صور المنتجات بوسترات طولية (نسبة 3:4 تقريبًا) وبتتعرض كاملة من غير قص.
- **أي صورة بترفعها من اللوحة بتتحوّل `webp` أوتوماتيك** في متصفحك قبل ما تترفع
  (`toWebP` في `assets/js/sb.js`). الأبعاد بتفضل زي ما هي لحد 2000px عشان الأسعار
  المكتوبة على البوسترات تفضل واضحة، ولو الأصل طلع أصغر من الناتج بيترفع الأصل.
- أسماء مجلدات وملفات صور المنتجات عربية وفيها مسافات — الكود بيرمّزها أوتوماتيك (`imgURL`).
- التحقق من رقم الموبايل مصري: 11 رقم يبدأ بـ 010 / 011 / 012 / 015.
- مفاتيح `localStorage`: `mr_cart_v1` (العربة) · `mr_catalog_v1` (نسخة الكتالوج للطوارئ) · `mr_orders_v1` (آخر 50 طلب في متصفح العميل) · `mr_sb_session` (جلسة دخول الأدمن).
- الروابط نضيفة من غير `.html`، والروابط القديمة بتحوّل أوتوماتيك.
